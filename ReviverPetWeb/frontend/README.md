# ReviverPet - Gestão de Pacientes

Sistema de Prontuário Veterinário e Dashboard de acompanhamento clínico.

## Tecnologias Utilizadas

- **Frontend**: React, Vite, Tailwind CSS, Lucide React, Framer Motion.
- **Backend/API**: FastAPI, SQLAlchemy (SQLite), Uvicorn.
- **Design**: Shadcn/ui.

## Como Iniciar

Para rodar o projeto localmente:

1. Execute o arquivo `Instalador_Geral.bat` na primeira vez para configurar as dependências.
2. Sempre que quiser usar, utilize o atalho `Iniciar Sistema.bat`.

## Estrutura do Projeto

- `/petreviver-flow`: Código fonte da interface React.
- `/backend`: Servidor API e banco de dados.
- `/exames`: Repositório físico de anexos e documentos.
